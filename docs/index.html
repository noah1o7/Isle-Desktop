Make Windows feel like home.

Isle adds a top bar, a Dynamic Island, a dock and a fresh start menu to Windows. Your apps stay exactly where they are, and quitting Isle puts everything back.

Download for Windows View the source

Free and open source, for Windows 10 (2004+) and Windows 11.

The island knows what's playing.

A small black pill sits at the top of your screen. When music plays it shows the cover and a few bouncing bars. Move the mouse over it and it opens into a card with everything you need.

  • Skip, pause and seek in Spotify, YouTube, VLC and any app that uses Windows media controls
  • Switch between speakers and headphones, or scroll over the island to change the volume
  • Type “18:30 laundry” and the island reminds you at 18:30
  • The moon turns on focus: no song pop-ups, reminders still come through

Try it: switch tabs, press play, add a reminder.

A top bar that reads your wallpaper.

The bar is transparent. Isle looks at what's behind it, left and right separately, and picks dark or white text so you can always read it.

  • Active app, weather, battery, keyboard language, date and time
  • A green or orange dot when an app uses your camera or microphone
  • Tray icons like Discord or Steam open right below the little arrow
  • Choose how bold the text is, from thin to bold

A dock that keeps up with you.

Your pinned apps, everything that's running, and a dot under each open app. Icons grow as the mouse passes over them.

  • Hover a running app to see live previews of its windows
  • Drag icons to reorder them, or drag one up and out to remove it
  • Right-click to close all windows or end a stuck app
  • Brings over the apps pinned to your Windows taskbar

Try it: move the mouse along the dock and rest on Mail.

Press the Windows key and start typing.

Isle's start menu opens in the middle of the screen. Type a few letters, press Enter, done. Shortcuts like Win+D and Win+L keep working as always.

  • All your apps, including Store apps, with sharp icons
  • Recent files and a web search when nothing matches
  • Lock, sleep, restart and shut down in one place

Try it: type into the search field and press Enter.

Your Windows stays yours.

Everything comes back

Isle hides the Windows taskbar only while it runs. Quit it, or even if it crashes, and a small watchdog brings the taskbar right back.

Nothing is installed

Isle is a single program file. It doesn't change system files, and it doesn't need administrator rights.

Nothing leaves your PC

No account, no tracking. The only connection is the weather from Open-Meteo, and only after you set a location.

Up and running in a minute.

  1. Download

    Get the ZIP file from the latest release on GitHub.

  2. Unzip and start

    Right-click, Extract All, then open Isle.exe. If Windows warns you, choose More info and Run anyway.

  3. Make it yours

    Click the pill in the top left for settings. To quit, press Ctrl Alt Q.

Questions

Is Isle a new operating system?

No. Isle is a program that runs on top of Windows. Windows and all your apps keep working the way they always do.

How do I get my normal taskbar back?

Quit Isle with Ctrl + Alt + Q, or untick “hide Windows taskbar” in the Isle menu. The taskbar is back instantly.

Why does Windows warn me the first time?

Isle isn't signed with a paid certificate, and Windows warns about every new unsigned program. The complete source code is public on GitHub.

Which languages does Isle speak?

The app itself is in German for now. An English interface is planned.

Is it free?

Yes. Isle is a free hobby project. No subscription, no ads, no account.
